# ix-memory-layer-dist

Pre-built releases of the Ix Memory Layer JAR.

This repo contains no source code. JAR artifacts are published here automatically when a new version of the memory layer is released from the private source repo.

## Usage

The JAR is primarily consumed via the Docker image:

```bash
docker pull ghcr.io/ix-infrastructure/ix-memory-layer:latest
```

For direct JAR access, see the [Releases](https://github.com/ix-infrastructure/ix-memory-layer-dist/releases) page.
